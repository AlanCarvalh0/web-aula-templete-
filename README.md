# Site de Notícias

## Resumo do projeto
Este projeto é uma página de notícias desenvolvida em HTML, CSS e JavaScript, com foco em apresentar conteúdos em um layout moderno e responsivo. A home exibe cards com diversas matérias, cada um com imagem, categoria, data, resumo e link para a página de detalhes.

Além disso, foi implementado um fluxo de cadastro com armazenamento local no navegador, permitindo criar usuários e salvar e-mails e senhas para uso no site. O layout também conta com um menu lateral interativo, melhorando a navegação na página inicial.

## Funcionalidades
- Home com listagem de notícias em cards
- Página de detalhes para cada matéria
- Menu lateral com toggle para mobile/desktop
- Cadastro de usuário com validação básica
- Armazenamento de dados em localStorage
- Design responsivo para diferentes tamanhos de tela
